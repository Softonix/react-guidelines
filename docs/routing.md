# Routing

Routing uses **React Router v7** in framework mode, running as a pure **SPA** (`ssr: false`). Routes are declared **programmatically** in `app/routes.ts`. There is **no `app/routes/` folder** and **no file-based routing**.

## Configuration

```ts
// app/routes.ts
import { type RouteConfig, index, layout, prefix, route } from '@react-router/dev/routes'

export default [
  layout('views/auth/ui/auth-layout.tsx', [
    route('sign-in', 'views/auth/ui/auth-sign-in-page.tsx'),
    route('sign-up', 'views/auth/ui/auth-sign-up-page.tsx'),
  ]),
  layout('views/items/ui/items-layout.tsx', [
    index('views/items/ui/items-list-page.tsx'),
    route(':id', 'views/items/ui/item-detail-page.tsx'),
  ]),
] satisfies RouteConfig
```

```ts
// react-router.config.ts
import type { Config } from '@react-router/dev/config'

export default {
  ssr: false,
} satisfies Config
```

`ssr: false` is the SPA flag. The build emits a static client bundle; everything renders in the browser.

## View UI = route component

Route component files live inside their view's `ui/` directory: `views/<view>/ui/<component>.tsx`. There is no thin route wrapper. The view file owns the **default export** and any client-side route exports (`meta`, `ErrorBoundary`, …).

```tsx
// app/views/items/ui/items-list-page.tsx
import { useState } from 'react'
import { useItemsList } from '~/entities/items'
import { SortControls, useSort } from '~/features/sort'
import { ItemsGrid } from './items-grid'
import type { Route } from './+types/items-list-page'

export function meta(_: Route.MetaArgs) {
  return [{ title: 'Items' }]
}

export default function ItemsListPage() {
  const [search, setSearch] = useState('')
  const { sortCriteria } = useSort()
  const { items, ...rest } = useItemsList({ search, sort: sortCriteria })
  return (
    <>
      <SortControls /* ... */ />
      <ItemsGrid items={items} {...rest} />
    </>
  )
}
```

## `+types/` imports

Each route view file imports its generated route types from a sibling `+types/<filename>` path:

```ts
import type { Route } from './+types/items-list-page'
```

The types are generated by `npm run typegen` (run as part of `npm run typecheck`).
